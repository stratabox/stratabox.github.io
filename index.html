Load only the blocks each rollout touches

Agent rollouts read roughly 4% to 13% of an image. StrataBox prefetches compact EROFS metadata locally and pages active 256 KiB chunks through a pure-Rust FUSE daemon.

128 stat() lookups hit local meta.erofs with 0 remote data chunk reads.

Burst latency 114 ms
Remote bytes pulled 10.08 MiB
Local disk writes 10.08 MiB
Speedup vs eager pull 2.93x

Across 16 concurrent sandboxes touching a 7.81% working set, cold L2 on-demand paging cuts remote transfer by 87.3% and local disk writes by 98.6%.

Storage architecture

Mount immutable layers without loop devices

Native file-backed Linux EROFS mounts consume zero /dev/loop devices and deduplicate concurrent mounts per node via DashMap reference counting.

Stacks Base, Workspace, and Toolkit under OverlayFS with offline compaction up to 3 GiB.

Page sparse working sets on demand

An embedded pure-Rust /dev/fuse daemon (fuse.stratabox) fetches 256 KiB chunks with singleflight deduplication into a persistent node-local L2 cache.

Directory walks and stat() probes read prefetched meta.erofs manifests with zero remote chunk I/O.

Snapshot VM disks with copy-on-write blocks

MicroVm and FullVm attach OverlayBD-style 256 KiB lazy-loading block devices with sparse dirty-block tracking for incremental snapshots.

Combined with virtio-pmem DAX so co-located guests share host physical page caches directly.

Pack dense sandboxes without noisy neighbors

All four benchmark suites from arXiv:2609.22978 run reproducibly on bare-metal Linux through stratabox-daemon bench.

Warm L2 on-demand paging cuts 16-sandbox burst startup from 334 ms to 11 ms (30.36x speedup) with 0.00 MiB remote chunk transfer and zero remote reads for 128 stat() probes.

Confine untrusted root workloads in depth

Models running as root inside evaluation sandboxes probe control sockets, tamper with shells, and leak solutions. StrataBox enforces six layered kernel defenses.

Live cgroup eBPF and nftables firewall

Attack vector
Agents exfiltrate test suites or pull remote solutions from PyPI, npm, or raw IP endpoints once grading begins.
Defense mechanism
Native 64-bit cgroup v2 connect4 and udp4_sendmsg eBPF socket programs pair with atomic per-netns nftables (stratabox_fw) ruleset swaps for sub-millisecond egress transitions via update_network_rules.
Kernel primitive

Start a local cluster in three commands

Build the Rust runtime, boot a multi-edge local cluster with automatic EROFS image bootstrap, and run sandboxes from the async Python SDK.

bash Compile release binaries for stratabox-agent and stratabox-daemon, then install stratabox. 
# 1. Build release binaries: in-sandbox agent and cluster/node CLI
cargo build --locked --release -p stratabox-agent -p stratabox-daemon

# 2. (Optional) Build 100% static musl stratabox-agent for Alpine or scratch images
CC_x86_64_unknown_linux_musl=gcc cargo build --locked --release \
  --target x86_64-unknown-linux-musl -p stratabox-agent

# 3. Install the unified async Python SDK (stratabox)
pip install "git+https://github.com/stratabox/stratabox-sdk-python.git"

Workspace architecture

stratabox-proto
Shared wire DTOs, typed error catalog, O(1) SandboxId codec, binary RPC framing, and core async traits.
stratabox-agent
Static musl in-sandbox daemon housing the aether UDS/AF_VSOCK multiplexer, chronus session worker, and POSIX sh fallback.
stratabox-storage
Composable EROFS/OverlayFS engine, pure-Rust /dev/fuse 256 KiB pager with L2 cache, VM CoW blocks, compaction, and pack_diff.
stratabox-sandbox
Four execution backends, cgroup v2 freeze and reclaim, eBPF and nftables firewall, AppArmor/Landlock/Seccomp, and PR_SCHED_CORE QoS.
stratabox-edge
Node daemon with atomic admission control, transparent PAUSED auto-resume, idempotent command replay cache, and TTL reaper.
stratabox-control
Stateless control plane with hierarchical IAM quotas, heartbeat Watcher, Power-of-k-Choices placement, and zero-state ApiServer.
stratabox-daemon
Unified CLI (cluster, control, edge, layer, bench), offline OCI/Docker importer, base image bootstrap, and benchmark suite.
stratabox
Async Python SDK covering all four backends, SandboxGroup batch rollouts, 429/503 retries, streaming sessions, and pack_diff.
